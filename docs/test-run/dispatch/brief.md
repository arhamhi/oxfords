# Brief: dispatch board (dark)

Product: Fieldline, dispatch software for small HVAC and plumbing companies.

Screen: the dispatcher's "Today" board for Northgate Heating & Air (14 technicians, 3 dispatchers, Columbus, Ohio). It is used on a 27-inch monitor in a dim back office from 6am, and sometimes on a laptop.

It must show:
- today's jobs and which technician each one is assigned to: some are unassigned, one technician is running late, and there is one emergency no-heat call
- each technician's status
- calls answered versus missed, by hour, so far today
- revenue booked this week, split across five job types: repair, maintenance, install, emergency, inspection

Dark theme. Desktop first; it must still work at 390px wide. Make assigning an unassigned job work (clicking through the assignment is enough).
